DESCRIPTION

This file provides the "int main()" function to wrap HdtnOneProcessRunner and forward command line arguments to HdtnOneProcessRunner. This file is only used when running HDTN in single-process mode in which there is a single process dedicated to the Ingress, Egress, Storage, and GUI modules.
