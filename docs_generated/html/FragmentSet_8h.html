DESCRIPTION

This FragmentSet static class provides methods to manage contiguous data fragments using an std::set<data_fragment_t> in order to determine what pieces of data are missing and need retransmitted. This class can be used for bytes of a packet or packet ids of a sequence of packets. Contiguous data that does not abut must be split up into pairs of start and end indices called a data_fragment_t. This class is used by LtpFragmentSet and AGGREGATE CUSTODY SIGNAL(ACS) / CUSTODY TRANSFER ENHANCEMENT BLOCK(CTEB)
