115  //4.2.6. DTN Time
116  //A DTN time is an unsigned integer indicating the number of
117  //milliseconds that have elapsed since the DTN Epoch, 2000-01-01
118  //00:00:00 +0000 (UTC). DTN time is not affected by leap seconds.
119  //Each DTN time SHALL be represented as a CBOR unsigned integer item.
120  //Implementers need to be aware that DTN time values conveyed in CBOR
121  //representation in bundles will nearly always exceed (2**32 - 1); the
122  //manner in which a DTN time value is represented in memory is an
123  //implementation matter. The DTN time value zero indicates that the
124  //time is unknown.
125  //4.2.7. Creation Timestamp
126  //Each bundle's creation timestamp SHALL be represented as a CBOR
127  //array comprising two items.
128  //The first item of the array, termed "bundle creation time", SHALL be
