DESCRIPTION

This LtpRandomNumberGenerator class defines methods for generating either 32 or 64 bit random numbers for LTP session numbers or LTP serial numbers using up to 3 sources of hardware randomness and birthday paradox prevention. These sources of randomness include microsecond time, boost::random_device, and optional x86 RDSEED instruction.
