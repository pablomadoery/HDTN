DESCRIPTION

This LtpClientServiceDataToSend class encapsulates the bundle or user data to send and keep persistent while an LTP session is alive and asynchronous UDP send operations are ongoing. The class can hold a vector<uint8_t> or a ZeroMQ message. Messages are intended to be moved into this class to avoid memory copies. The data is then able to be destroyed once the LTP send session completes/closes.
