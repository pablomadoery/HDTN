DESCRIPTION

This CpuFlagDetection class file is used for detecting the current processor's CPU flags to determine which CPU instructions are supported. It is cross platform. It is used by this project's CMake build system when compiling locally (not cross-compiling) to determine if any hardware accelerated functions should be compiled in. For more information, see the example from https://docs.microsoft.com/en-us/cpp/intrinsics/cpuid-cpuidex?view=msvc-170 which this code is based on. Also see https://www.boost.org/doc/libs/master/boost/beast/core/detail/cpu_info.hpp from which the cross platform code idea is based on.
