DESCRIPTION

This LtpIpcEngine class is a child class of LtpEngine. It implements LTP over Interprocess Communication (IPC). It is used for benchmarking ONLY. Its purpose is to find the theoretical max rate between two LTP processes by completely bypassing the OS UDP network layer.
