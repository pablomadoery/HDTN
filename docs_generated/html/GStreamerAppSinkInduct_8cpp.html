◆ s_wholeBundleReadyCallback

WholeBundleReadyCallback_t s_wholeBundleReadyCallback
static

I do not know if there is a better way to do this. The problem is complicated:

  1. We can not use member functions for the GStreamer callbacks since they are pure C and do not support the 'this' keyword.
  2. Therefore we can not set a callback function the usual way in the constructor.
  3. The callback function can not be a member of the class since the Gstreamder callbacks are not member functions
