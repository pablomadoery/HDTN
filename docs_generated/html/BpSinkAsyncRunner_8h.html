DESCRIPTION

This BpSinkAsyncRunner class is used for launching the BpSinkAsync class into its own process. The BpSinkAsyncRunner provides a blocking Run function which creates and initializes a BpSinkAsync object by processing/using the various command line arguments. BpSinkAsyncRunner also provides a signal handler listener to capture Ctrl+C (SIGINT) events for clean termination.
