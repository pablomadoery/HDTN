DESCRIPTION

The BundleViewV6 class is a helper class for reading/parsing/validating all blocks within Bundle Protocol Version 6 bundles. The class makes it easy to modify specific blocks and rewrite (rerender) bundles to new memory. The class keeps track of which blocks have been modified (marked dirty) so that SDNV serializaton does not need to be performed on unmodified blocks during a rerender. See TestBundleViewV6.cpp for usage examples.
