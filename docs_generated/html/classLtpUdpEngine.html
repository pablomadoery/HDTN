◆ PostPacketFromManager_ThreadSafe()

void LtpUdpEngine::PostPacketFromManager_ThreadSafe ( std::vector< uint8_t > &  packetIn_thenSwappedForAnotherSameSizeVector,
std::size_t  size 
)

If the receive buffers are full, the packet is dropped. Else, swaps in the packet to the receive buffer and calls LtpEngine::PacketIn_ThreadSafe() to forward to the underlying LtpEngine for processing. packetIn_thenSwappedForAnotherSameSizeVector holds the entire receive buffer, only the first 'size' bytes belong in the current packet and are therefore safe to read, any bytes that follow may contain partial data from previously processed packets and should be treated as garbage values.

Parameters
packetIn_thenSwappedForAnotherSameSizeVectorThe packet to transmit.
sizeThe size of the packet.
Postcondition
The argument to packetIn_thenSwappedForAnotherSameSizeVector is swapped with a potentially dirty buffer of an already-processed packet and is ready to be reused as the receive buffer for the next read operation (see above how to handle dirty buffers).
