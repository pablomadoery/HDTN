DESCRIPTION

This Ltp class defines data structures used in the LTP library, defines methods for encoding LTP headers (segments), and defines methods for finite-state machine (FSM) receiving of all bytes or partial bytes of an LTP message with custom callback functions that (if the function is defined) get called whenever the appropriate number of bytes is received.
