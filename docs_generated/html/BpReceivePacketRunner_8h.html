DESCRIPTION

This BpReceivePacketRunner class is used for launching the BpReceivePacket class into its own process. The BpReceivePacketRunner provides a blocking Run function which creates and initializes a BpReceivePacket object by processing/using the various command line arguments. BpReceivePacketRunner also provides a signal handler listener to capture Ctrl+C (SIGINT) events for clean termination.
