DESCRIPTION

This BpSendFileRunner class is used for launching the BpSendFile class into its own process. The BpSendFileRunner provides a blocking Run function which creates and initializes a BpSendFile object by processing/using the various command line arguments. BpSendFileRunner also provides a signal handler listener to capture Ctrl+C (SIGINT) events for clean termination.
