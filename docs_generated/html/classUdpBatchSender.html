◆ Stop()

void UdpBatchSender::Stop ( )

Perform graceful shutdown.

If no previous successful call to UdpBatchSender::Init(), returns immediately. Else, tries to perform graceful shutdown on the socket, then releases all underlying I/O resources.

Postcondition
The object is ready to be reused after the next successful call to UdpBatchSender::Init().
