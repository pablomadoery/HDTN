Perform a packet batch send operation.

Performs a single synchronous batch send operation. After it finishes (successfully or otherwise), the callback stored in m_onSentPacketsCallback (if any) is invoked.

Parameters
constBufferVecsThe vector of data buffers to send.
underlyingDataToDeleteOnSentCallbackVecThe vector of underlying data buffers shared pointer.
underlyingCsDataToDeleteOnSentCallbackVecThe vector of underlying client service data to send shared pointers.
Postcondition
