DESCRIPTION

This Tcpcl class implements RFC 7242 (version 3 of the TCP Convergence-Layer Protocol). It defines methods for encoding TCPCL headers (segments) and defines methods for finite-state machine (FSM) receiving of all bytes or partial bytes of a TCPCL message with custom callback functions that (if the function is defined) get called whenever the appropriate number of bytes is received.
