DESCRIPTION

The BpSinkAsync class is a child class of BpSinkPattern. It is an app used for receiving any size bundles from the BpGen app. The app reads a tiny payload at the beginning of the bundle payload block used for counting bundles (in order or out of order). This app is intended to be used with the BpGen app.
