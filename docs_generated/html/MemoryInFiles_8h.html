DESCRIPTION

This MemoryInFiles class is used for asynchronous reads of memory from storage and writes of memory to storage. The intention is to allow LTP to use this as a storage mechanism for long delays and high rates which would require too much RAM otherwise. It is single threaded and must be run by the thread running ioServiceRef.
