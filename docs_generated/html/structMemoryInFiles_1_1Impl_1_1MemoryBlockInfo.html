bool MemoryInFiles::Impl::MemoryBlockInfo::DoWriteOrRead ( const uint64_t  deferredOffset,
const uint64_t  deferredLength,
void *  readToThisLocationPtr,
const void *  writeFromThisLocationPtr,
void *  handlerPtrPtr 
)

Initiate a read or write operation. If the block is due deletion or the data length to operate on exceeds the allocated size of the block, returns immediately. Else, acts accordingly to the following cases:

  1. When (readToThisLocationPtr == NULL), we are attempting to queue a write operation, calls FileInfo::WriteMemoryAsync() on each eligible fragment.
  2. When (writeFromThisLocationPtr == NULL), we are attempting to queue a read operation, calls FileInfo::ReadMemoryAsync() on each eligible fragment. Eligible is any fragment that overlaps with the range we are operating on [deferredOffset, (deferredOffset + deferredLength)], as such if N fragments are eligible, this function will queue N individual I/O operations.
    Parameters
    deferredOffsetThe target memory block offset.
    deferredLengthThe data length in bytes to read or write.
    readToThisLocationPtrType-erased output begin pointer in case of read, NULL on write.
    writeFromThisLocationPtrType-erased input begin pointer in case of write, NULL on read.
    handlerPtrPtrType-erased I/O completion handler pointer.
    Returns
    True if the operation could be queued successfully, or False otherwise.

const uint64_t  currentBaseOffsetWithinFile,

Resize this memory block. If new length is smaller than the current length, returns immediately with a value of 0. Else, on the current active write file creates a new fragment that covers the length difference, thus expanding this memory block by the desired amount.

Parameters
currentFileInfoPtrThe current active write file.
currentBaseOffsetWithinFileThe current active file offset to begin writing from.
newLengthAlignedToBlockSizeThe target memory block length in bytes.
Returns
The increase in size (NOT the total size of the new allocation) if resizing to a larger length, or 0 if the new length is smaller than the current length.
