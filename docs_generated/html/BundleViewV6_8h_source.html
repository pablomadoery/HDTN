39 
40 Each bundle shall be a concatenated sequence of at least two block
41 structures. The first block in the sequence must be a primary bundle
42 block, and no bundle may have more than one primary bundle block.
43 Additional bundle protocol blocks of other types may follow the
44 primary block to support extensions to the bundle protocol, such as
45 the Bundle Security Protocol [BSP]. At most one of the blocks in the
46 sequence may be a payload block. The last block in the sequence must
47 have the "last block" flag (in its block processing control flags)
48 set to 1; for every other block in the bundle after the primary
49 block, this flag must be set to zero.
50 
51 To keep from possibly invalidating bundle security, the sequencing
52 of the blocks in a forwarded bundle must not be changed as it
53 transits a node; received blocks must be transmitted in the same
54 relative order as that in which they were received. While blocks
55 may be added to bundles as they transit intermediate nodes,
56 removal of blocks that do not have their 'Discard block if it
57 can't be processed' flag in the block processing control flags set
58 to 1 may cause security to fail.
59 
60 Bundle security must not be invalidated by forwarding nodes even
61 though they themselves might not use the Bundle Security Protocol.
62 In particular, the sequencing of the blocks in a forwarded bundle
63 must not be changed as it transits a node; received blocks must be
64 transmitted in the same relative order as that in which they were
65 received. While blocks may be added to bundles as they transit
66 intermediate nodes, removal of blocks that do not have their 'Discard
67 block if it can't be processed' flag in the block processing control
68 flags set to 1 may cause security to fail.
69 
70 A bundle MAY have multiple security blocks.
71 */
