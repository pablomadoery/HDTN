DESCRIPTION

This PaddedVectorUint8 templated class is a custom allocator intended for std::vector<uint8_t>. This allocator adds contiguous bytes of padding before and after a vector (used by an induct) so that bundles can be manipulated in place (grow a few bytes in either direction) without the need to reallocate/copy a modified bundle.
