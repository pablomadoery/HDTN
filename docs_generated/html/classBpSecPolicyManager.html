BpSecPolicy * BpSecPolicyManager::CreateOrGetNewPolicy ( const std::string &  securitySourceEidUri,

Creates a new BpSecPolicy. Eid Uri parameters may be in the following form:

  • The fully qualified [node,service] pair.
  • The node number only (for wildcard service numbers such as "ipn:2.*").
  • The "any eid" (for wildcard all such as "ipn:*.*").
Parameters
securitySourceEidUriThe uri to match of the security source field of the Abstract Security Block (ASB). This field should be "ipn:*.*" for a role of "security source" since the ASB won't exist.
bundleSourceEidUriThe uri to match of the bundle source field of the primary block.
bundleFinalDestEidUriThe uri to match of the bundle destination field of the primary block.
roleThe Bpsec role of this policy.
isNewPolicyOn return, this value is set to false if the policy already exists, or true if the policy was newly created
Returns
A pointer of the newly allocated policy that needs modified (does not need deleted, handled internally). NULL if a URI was invalid.

const BpSecPolicy * BpSecPolicyManager::FindPolicy ( const cbhe_eid_t &  securitySourceEid,

const cbhe_eid_t &  bundleFinalDestEid,

Finds an existing BpSecPolicy using the fully-qualified eid fields of the bundle. The EID is matched to the most strictest (most fully qualified) set of rules. Lookup shall be performed by a Cascading lookup order:

  • The fully qualified [node,service] pair is looked up first for a match.
  • The node number only is looked up second for a match (for wildcard service numbers such as "ipn:2.*").
  • The "any destination flag" is looked up third for a match (for wildcard all such as "ipn:*.*").
Parameters
securitySourceEidThe eid to match of the security source field of the Abstract Security Block (ASB). This field is a "don't care" for a role of "security source" if the policy was added properly.
bundleSourceEidThe eid to match of the bundle source field of the primary block.
bundleFinalDestEidThe eid to match of the bundle destination field of the primary block.
roleThe Bpsec role of this policy.
Returns
A pointer of the existing policy, or NULL if no policy could be matched.
