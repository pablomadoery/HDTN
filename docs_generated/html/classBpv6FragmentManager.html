Add fragment to collection, if final fragment then return completed bundle

Parameters
dataThe encoded fragment bundle data
lenLength in bytes of the encoded fragment bundle data
isComplete[out]True if bundle completed by fragment added, false otherwise
assembledBv[out]If complete, populated with the assembled bundle

If the fragment bundle is successfully added and it completes the bundle, the non-fragmented bundle will be assembled in assembledBv.

Upon successfully assembling the non-fragmented bundle, the fragments are deleted from the manager.

Returns
true on successfully adding the fragment, false on error
