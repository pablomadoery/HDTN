int GStreamerAppSinkInduct::BuildPipeline ( )
private

Elements can not be linked until their pads are created. Pads on the qtdemux are not created until the video source provides "enough information" to the plugin that it can determine the type of media. We hook up a callback function here to link the two halves of the pipeline together when the pad is added
