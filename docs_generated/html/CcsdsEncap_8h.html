DESCRIPTION

This is a header-only library for LTP/BP/IDLE encapsulation packet defines. Encode and decode functions are in CcsdsEncapEncode.h and CcsdsEncapDecode.h, respectively. Based on: Encapsulation Packet Protocol: https://public.ccsds.org/Pubs/133x1b3e1.pdf
