DESCRIPTION

The BpReceiveFile class is a child class of BpSinkPattern. It is an app used for receiving file-fragment bundles from the BpSendFile app and writing those files to disk within a directory and preserving the sender's relative path names. This app is intended to be used with the BpSendFile app. It is acceptable if the bundles arrive out-of-order.
