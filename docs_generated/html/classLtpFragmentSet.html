bool LtpFragmentSet::SplitReportSegment ( const Ltp::report_segment_t &  originalTooLargeReportSegment,
std::vector< Ltp::report_segment_t > &  reportSegmentsVec,
const uint64_t  maxReceptionClaimsPerReportSegment 
)
static

Split report segment by reception claims.

If the split factor is set to 0, returns immediately and the report segment vector is left unmodified. Else, the reception claims of the report segment to split are grouped every maxReceptionClaimsPerReportSegment claims and placed in their own report segment, the last report segment in the vector may be left with a number of claims LESS-THAN maxReceptionClaimsPerReportSegment on an odd split.

This function is typically used to split an excessively large report segment (as per MTU constraints) into multiple smaller report segments.

Parameters
originalTooLargeReportSegmentThe report segment to split.
reportSegmentsVecThe report segment vector to modify.
maxReceptionClaimsPerReportSegmentThe maximum number of reception claims per resulting report segment, this split factor.
Returns
True if the report segment could be split successfully (and thus the report segment vector was modified), or False otherwise.
Postcondition
If returns True, the argument to reportSegmentsVec is modified accordingly (see above for details).
