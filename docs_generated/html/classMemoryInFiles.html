◆ DeleteMemoryBlock()

bool MemoryInFiles::DeleteMemoryBlock ( const uint64_t  memoryBlockId)

Delete the given memory block.

If the given memory block ID does not reference a valid memory block, returns immediately.

if the memory block has pending I/O operations queued, then if not already marked, marks the block as due deletion (deferred for after the I/O operations have been completed, deferred deletion is eventually handled by Impl::ForceDeleteMemoryBlock()). Else, deletes the memory block.

Parameters
memoryBlockIdThe memory block ID.
Returns
True if the memory block was JUST NOW marked as due deletion or was JUST NOW deleted, or False otherwise.
