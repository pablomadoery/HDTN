DESCRIPTION

This LtpUdpEngineManager class is singleton pattern class used to share UDP sockets that bind to the same UDP port with various LtpUdpEngine(s). It manages a bidirectional udp socket paired with its own boost::asio::io_service and thread. It quickly examines the first few bytes of incoming UDP packets so that it can route them to their proper LtpUdpEngine.
