41 /*
42 Each bundle SHALL be a concatenated sequence of at least two blocks,
43 represented as a CBOR indefinite-length array. The first block in
44 the sequence (the first item of the array) MUST be a primary bundle
45 block in CBOR representation as described below; the bundle MUST
46 have exactly one primary bundle block. The primary block MUST be
47 followed by one or more canonical bundle blocks (additional array
48 items) in CBOR representation as described in 4.3.2 below. Every
49 block following the primary block SHALL be the CBOR representation
50 of a canonical block. The last such block MUST be a payload block;
51 the bundle MUST have exactly one payload block. The payload block
52 SHALL be followed by a CBOR "break" stop code, terminating the
53 array.
54 
55 (Note that, while CBOR permits considerable flexibility in the
56 encoding of bundles, this flexibility must not be interpreted as
57 inviting increased complexity in protocol data unit structure.)
58 
59 Associated with each block of a bundle is a block number. The block
60 number uniquely identifies the block within the bundle, enabling
61 blocks (notably bundle security protocol blocks) to reference other
62 blocks in the same bundle without ambiguity. The block number of
63 the primary block is implicitly zero; the block numbers of all other
64 blocks are explicitly stated in block headers as noted below. Block
65 numbering is unrelated to the order in which blocks are sequenced in
66 the bundle. The block number of the payload block is always 1.
67 
68 An implementation of the Bundle Protocol MAY discard any sequence of
69 bytes that does not conform to the Bundle Protocol specification.
70 
71 An implementation of the Bundle Protocol MAY accept a sequence of
72 bytes that does not conform to the Bundle Protocol specification
73 (e.g., one that represents data elements in fixed-length arrays
74 rather than indefinite-length arrays) and transform it into
75 conformant BP structure before processing it. Procedures for
76 accomplishing such a transformation are beyond the scope of this
77 specification.
78 */
