Detailed Description

This class effectively acts as a tracker for all the pertinent RTP frame information such as timestamp, ssrc, number of packets sent, clock rate etc

◆ GetNumConcatenated()

uint16_t DtnRtp::GetNumConcatenated ( )

This returns the number of times the current frame has been added to. A frame with no data is zero. A frame that has been added to once is 1. A frame that has been added two twice is 2. and so on.
