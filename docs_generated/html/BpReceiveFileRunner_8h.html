DESCRIPTION

This BpReceiveFileRunner class is used for launching the BpReceiveFile class into its own process. The BpReceiveFileRunner provides a blocking Run function which creates and initializes a BpReceiveFile object by processing/using the various command line arguments. BpReceiveFileRunner also provides a signal handler listener to capture Ctrl+C (SIGINT) events for clean termination.
