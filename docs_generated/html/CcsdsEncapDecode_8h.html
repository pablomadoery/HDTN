Decode the first byte of a CCSDS Encap header. See CcsdsEncap.h for a picture description of the packet.

Parameters
typeThe non-idle SANA type of encap packet expected to be decoded.
firstByteThe first byte of the Encap header to decode.
Returns
1, 2, 4, or 8 on success (denoting the size of the encap header), or 0 on failure.

Decode the second to remaining byte(s) of a CCSDS Encap header, called after the DecodeCcsdsEncapHeaderSizeFromFirstByte function.

Parameters
encapHeaderLengthThe 1, 2, 4, or 8 byte size of encap packet expected to be decoded. This function need not be called if this value is 1.
secondByteThe pointer to the start of the second byte of the Encap header to decode.
userDefinedFieldThe returned user defined field of the Encap packet (usually 0) if encapHeaderLength is 4 or 8 bytes.
payloadSizeThe returned payload size (i.e. size of the data being encapsulated) if encapHeaderLength is 2, 4, or 8 bytes.
Returns
true on success (denoting valid userDefinedField and payloadSize), or false on failure.
