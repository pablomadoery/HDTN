Handle a UDP receive operation.

◆ QueuePacketForDelayedSend_NotThreadSafe()

void UdpDelaySim::QueuePacketForDelayedSend_NotThreadSafe ( std::vector< uint8_t > &  udpPacketToSwapIn,
std::size_t  bytesTransferred 
)

Queue packet for delayed transmission.

Timestamps the packet for transmission clearance using the configured transmission delay duration, then places the packet in the transmission queue. udpPacketToSwapIn holds the entire receive buffer with a size of M_MAX_UDP_PACKET_SIZE_BYTES, only the first bytesTransferred bytes belong in the current packet and are therefore safe to read, any bytes that follow may contain partial data from previously processed packets and should be treated as garbage values.

Parameters
udpPacketToSwapInThe packet to transmit.
bytesTransferredThe size of the packet.
Postcondition
The argument to udpPacketToSwapIn is swapped with a potentially dirty buffer of an already-processed packet and is ready to be reused as the receive buffer for the next read operation (see above how to handle dirty buffers).

bool UdpDelaySim::StartIfNotAlreadyRunning ( )

Start the UDP server and initiate resolving of the forwarding destination endpoint.

If the server is already running, returns immediately. Starts the stat tracking interval loop, then starts the server. Initiates an asynchronous resolve operation to resolve the forwarding destination endpoint with UdpDelaySim::OnResolve() as a completion handler.

Returns

Postcondition
If the server was not already running, the server will NOT be listening for packets yet.

◆ TryRestartSendDelayTimer()

void UdpDelaySim::TryRestartSendDelayTimer ( )
private

Start the delay timer for the next packet in the transmission queue.

If the timer is already running or there are no packets available in the transmission queue, returns immediately. Else, starts the transmission delay timer asynchronously for the next packet in the transmission queue with OnSendDelay_TimerExpired() as a completion handler. The timer runs for the remaining delay duration (if any left) from the time the packet was enqueued for transmission.
