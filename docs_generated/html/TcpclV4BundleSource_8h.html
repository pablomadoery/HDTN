DESCRIPTION

This TcpclV4BundleSource class encapsulates the appropriate TCPCL version 4 functionality to send a pipeline of bundles (or any other user defined data) over a TCPCL version 4 link (either encrypted or not) and calls the user defined function OnSuccessfulAckCallback_t when the session closes, meaning a bundle is fully sent (i.e. gets acknowledged by the remote receiver).
