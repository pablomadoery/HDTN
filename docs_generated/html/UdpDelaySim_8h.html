DESCRIPTION

This UdpDelaySim class is a proxy server which delays incoming udp packets by a specified millisecond delay before forwarding those packets on to the specified remote destination. The direction is one way, so create two separate instances/processes of UdpDelaySim in order to achieve bidirectional communication such as LTP.
