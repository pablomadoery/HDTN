◆ Stop()

void EncapAsyncDuplexLocalStream::Stop ( )
inline

Perform graceful shutdown, called by an external thread not running the io_service. Warning, if Stop() is called from within the thread running the io_service, the function will hang.

If no previous successful call to Init(), returns immediately. Else, tries to perform graceful shutdown on the socket, then releases all underlying I/O resources.

Postcondition
The object is ready to be reused after the next successful call to Init().
