Delete expired bundles

Deletes expired bundles from disk per storage deletion policy.

If storage is less full than DELETE_ALL_EXPIRED_THRESHOLD, then at most MAX_DELETE_EXPIRED_PER_ITER bundles are deleted. Otherwise, all expired bundles are deleted. (Avoid blocking event loop unless full).
