DESCRIPTION

This UdpBundleSink class encapsulates the appropriate UDP functionality to receive bundles (or any other user defined data) over a UDP socket and calls the user defined function WholeBundleReadyCallback_t when a new bundle is received. This class assumes an entire bundle is small enough to fit entirely in one UDP datagram.
