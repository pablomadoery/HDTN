DESCRIPTION

This BPingRunner class is used for launching the BPing class into its own process. The BPingRunner provides a blocking Run function which creates and initializes a BPing object by processing/using the various command line arguments. BPingRunner also provides a signal handler listener to capture Ctrl+C (SIGINT) events for clean termination.
