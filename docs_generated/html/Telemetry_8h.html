DESCRIPTION

This Telemetry class is used for launching the telemetry runner in its own process. The common use-case for this functionality is when running HDTN in distributed mode. Telemetry provides a blocking Run method, which creates and initializes a TelemetryRunner object with any passed-in command line arguments.
